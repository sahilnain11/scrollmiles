# README screenshot provenance

These are reviewed, compressed copies of production-extension screenshots from the local Chromium integration suite. Activity was generated by scripted scrolling on loopback fixtures in disposable profiles. It is **illustrative test activity, not the owner's browsing history**, and no sample records are added to the shipped extension.

The views come from separate tests, so totals and capture times can differ. The popup is the actual production popup document in a bounded browser tab, not a capture of Chrome's physical toolbar window. Website insights was explicitly enabled in its test; it stays off by default in production. The Wrapped screenshot shows the real generated PNG preview after an explicit test download.

| Asset | Capture source | Preparation |
| --- | --- | --- |
| Dashboard dark/light | [Production extension suite](../../tests/e2e/extension.spec.ts) | Crop outer margins and lower sections, retaining the header, summary, metrics, seven-day chart and Wrapped entry |
| Popup dark | [Popup suite](../../tests/e2e/popup.spec.ts) | Full screenshot, 390 × 600 |
| Wrapped preview dark | [Wrapped suite](../../tests/e2e/wrapped.spec.ts) | Full dialog screenshot |
| Website insights dark/light | [Website insights suite](../../tests/e2e/site-insights.spec.ts) | Full section screenshot with synthetic exact hosts |

All six images use lossless WebP compression with metadata stripped. No numbers, dates, labels, site names, or chart bars are edited. The dashboard crop does not imply the rest of the page is absent. Light/dark dashboard and insights variants let the root README follow the reader's preferred color scheme; other views show the dark theme.

## Refreshing the images

1. Run the production build and complete Chromium suite described in the [development instructions](../../README.md#development).
2. Inspect the resulting screenshots for visual correctness and ensure they contain only local-fixture activity.
3. Run `node scripts/prepare-readme-images.mjs` from the repository root. The [preparation script](../../scripts/prepare-readme-images.mjs) selects only these six filenames, refuses ambiguous/missing inputs, and checks the dashboard geometry before cropping.
4. Inspect the output and root README before committing. Do not copy raw reports, browser profiles, personal activity, or unrelated test output into this directory.

The original screenshots and remaining test output stay ignored. This directory is a curated documentation exception, not an automatic publishing destination for test runs. These are beta documentation visuals, not store-ready marketing or proof of manual/device accessibility testing.
